# Shreya Shukla — Portfolio

A personal portfolio for Shreya Shukla, built to showcase projects, experience, skills, and resume access using a modern interactive frontend.

## Tech Stack

- React
- TypeScript
- TanStack Start
- Tailwind CSS
- Framer Motion
- Three.js
- React Three Fiber
- React Three Drei

## Features

- Interactive 3D hero
- Responsive design
- Framer Motion animations
- Project showcase
- Experience timeline
- Skills section
- Resume download
- Live project demos
- Accessibility support

## Development

This project uses Bun as the package manager.

```bash
bun install
bun run dev
```

## Production Build

```bash
bun run build
bun run preview
```

## Deployment

The app is configured for a static-plus-server TanStack Start production build and is ready to deploy to a Node-compatible hosting platform such as Vercel or similar. Build the project with `bun run build`, then deploy the generated output using your platform's standard server deployment workflow.

## Resume and Assets

- Logo: `/assets/shreya-logo.png`
- Resume: `/assets/resume.pdf`

The portfolio loads the logo and resume from local public assets for independent deployment.
